# Remote Terminal (Web)

Browser client for [Remote Terminal](https://github.com/w3sourcecode/remote-terminal).

**Live app:** https://remote-terminal.github.io/

Connect to your PC by scanning the QR code on the desktop agent or entering a session ID. Requires the desktop app and cloud API (`terminal.billten.com`).

## Deploy

Built from `w3sourcecode/remote-terminal` (mobile Angular app):

```bash
node scripts/publish-web-github-pages.mjs
```
